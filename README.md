## Лабораторная работа № 3

На JavaScript реализован набор функций:

- **`isInteger`** — функция проверки, что число целое.
- **`even`** — функция, возвращающая массив чётных чисел от 2 до 20.
- **`sumTo`** — функция суммы чисел до заданного (цикл).
- **`recSumTo`** — функция суммы чисел до заданного (рекурсия).
- **`factorial`** — функция вычисления факториала числа.
- **`isBinary`** — функция проверки, что число является степенью двойки.
- **`fibonacci`** — функция поиска N-го числа Фибоначчи.
- **`getOperationFn`** — функция, которая хранит значение и применяет к нему операцию.
- **`sequence`** — функция создания генератора арифметической последовательности.
- **`deepEqual`** — функция глубокого сравнения значений и объектов.
